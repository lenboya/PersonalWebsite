Learning CSS

Introduction

CSS stands for Cascading Style Sheet. CSS is essentially the artist of the page. It is used to make the HTML structure look good and have a style.

Elements come with default styles provided by the browser, for example the button element. We use a style sheet to change these default behaviors. Somtimes we are working against these default behaviors which may cause some unintended outcomes.

Cascade

The Cascade portion of CSS is what determines which rules are implemented into the final CSS style and how the browser will resolve declarations. For example an ID Selector has the highest precedence, then class, then type. The more specific a CSS declaration the higher the precedence.

So when it comes to CSS not properly working in your favor, review the Cascade portion of your Stylesheet.

Using CSS

There are three ways you can add CSS to HTML

  • External CSS
  • Internal CSS
  • Inline CSS

This page goes over external CSS. This is generally the most often used method. External CSS involves creating a separate file called a stylesheet "styles.css". We link the style sheet to the html page using the link element within the head element.

< link rel="stylesheet href=style.css">

The href attribute is where the CSS file is located, the rel attribute specifies the relationship between the linked file and the HTML file.

Internal css requires adding a <style> element within the <header> body

Inline CSS is added using the "style" attribute within an element tag

<p "style=background-color:red;"> Element Content </p>

CSS Syntax

A CSS line of code contains a selector, some property and a value. Selectors are the HTML element we are lookign to apply a css rule too. There is quite an indepth selection of selectors so lets go over them.

Selectors

Universal Selector

A universal selector will select all elements of an HTML page. It is a simple asterisk. The code below will change every element to the color red.

* {color:red;}

Element Selector

An Element selector will select the elements of the given element specified

p{color:blue;}

All the elements of the p type, will now be colored blue

Class Selector

Elements can be given a unique class that differentiates the element from others. CSS can then be applied to that specific element using its class name. The syntax is a period followed by the class name.

<h2 class="Header"> Header 2 </h2>
.header {color:black;}

CSS Properties

Text Styling

There are many ways you can style text using CSS. The color property will change an elemets text color. background-color sets the background color of an element. Both of these properties values can be set using an actual color name, or values such as HEX, RGB, or HSL.

The font of an element can be changed using the property font-family and giving a value of a font family name.

If the browser can not find the font, it will use the next available one until a supported one is found.

  • color
  • border-color
  • font-size
  • font-family

Box Model

Everything within a webpage, is essentially a rectangle that can be nested within each other, and positioned around each other.

Every box has a padding, border, and margin. Allowing you to manipulate a boxes size.

In the box model, margin collapses between two elements when they are next to each other

The height and width of a box will take into account the border and padding into its overall value

Flexbox

Flexbox is another way to design the website using the Box model. It is a way of arranges boxes in rows and columns, that will shrink or grow dependent on the CSS rules define.

A flex container holds flex items. A flex container is declared in CSS using the property diplay:flex; Note: an element can be both a flex container and flex item. This is key, as the design of a webpage with flex will contain multiple nested flex containers and items.

Flex Properties

  • display
  • flex - shorthand property for flex-grow, flex-shrink, flex-basis
  • flex-grow: Applies a growth factor
  • flex-shrink: similar to flex grow but applies a shrink factor, size of items must be larger than parent
  • flex-basis: sets initial size of a flex item
  • flex-direction: sets direction of flex container, default is row(horizontal)
  • justify-content: aligns items along its main axis
  • align-items: aligns content along the cross axis
  • gap: adds specified space between flex items
