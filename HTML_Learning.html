Learning HTML

Introduction

This page is dedicated to explaining HTML and its Syntax.

HyperText Markup Language or HTML for short, defines the structure and content of a webpage. HTML is used to create paragraphs, Headings, Lists, Tables, Buttons, Images, Links and much more.

General Syntax

All content defined on a page is wrapped inside a HTML Tag. HTML Tags are the essential building blocks.

<> </>

Opening Tags <> consist of keyword that will tell the page how to structure it

Closing Tags </> will terminate the tag you opened with.

Some common tags are

  • < p >
  • < h1 - h6 >
  • < img >
  • < link >

A full list of Tags can be found here: HTML Tags

<p> Some content here </p>

All though most elements will have a closing tag, some do not and close within a self closing tag

<img />

HTML Structure

All HTML documents generally will have the same layout to start, called a boilerplate.

<!DOCTYPE html >
<html lang="en">
<head>
</head>
<body>
</body>
</html>

<html> element is what is called the root element. Every other element is a descendant of the root.

<head> element is where meta-data of the website is located. Containing things like page title, meta charset

<body> element contains all content that is displayed on the HTML page.

A website to test your boilerplate for any syntax errors is HTML validator

HTML Text

At the core of HTML, it is just working with text. Content on the web is mostly text based. HTML has elements for creating paragraphs, headings, bolding words, italicizing, listing text and much more.

  • <p> - used to create paragraphs.
  • <strong> - makes text bold, and semantically marks the text as important for accessibility features.
  • <em> - italics textm also semantically marks the text for accessibility features.
  • <ul> - Creates an unordered list. Like this current one.
  • <ol> - Create an Ordered list. Elemets of the ordered list are numbered.
